BMC-01 · Design Playbook v5

暗色 IDE Demo 设计手册

从 54 次提交、25 次 polish、3 次架构重构中提炼出的设计决策、组件规格与页面脚手架。写给下一次做类似项目的设计师。

三条元规则

所有具体经验的上位原则。

01

做减法比做加法难，但更重要

60% 的 polish 提交是在删东西——删按钮、删标签、删描边、删统计条、收提示进 hover。新组件上线时先只放必要信息，后续按需加回来。

02

布局方案必须同时回答「全局」和「局部」

报警配置经历了浮层卡→泳道→节点图→泳道+浮层卡四次迭代。类似配置型 UI 应在概念设计阶段就把「全局概览」与「单项深编辑」两个维度画出来。

03

视觉约束必须自动化

色值禁用列表、描边上限、滚动条规则——只写在文档里会不断被违反。用 check-ui-style.mjs + PostToolUse hook 实现自动拦截。当一个问题出现第 2 次，写进文档；第 3 次，写成自动检查。

视觉原则

暗色 IDE 主题下反复验证过的视觉决策。

填充

填充优先，减少描边（Fill over Stroke）

卡片/按钮/chip 用 --surface-* 灰阶分层替代 border。每页白描边上限 2 处（R4 自动检查）。分隔线用 rgba(255,255,255,.06) 的 border-bottom 细线。Tag 背景用 color-mix(in srgb, var(--color) 20%, transparent)。

图标

面型图标，统一 AI 标识

图标用 fill="currentColor" 面型。AI/agent 入口统一四角星面型 + #a78bfa 紫色，path 固定为 M12 2l1.9 6.1L20 10...。禁止描边星形、机器人、对话泡（R3 自动检查）。

文字

三级透明度文本体系

主文本 .90、辅助 .60、弱化 .40。标题 20px/700，section 16px/650，卡片标题 14px/600，正文 13px/400，标签 12px/500。

造型

胶囊 + 大圆角

按钮/chip/输入框 border-radius: 100px；卡片 16px；IDE 面板 8px。Pane 实底 var(--background)，禁止半透明玻璃底。

分屏树（Split Pane）逻辑

Workarea 内容是一棵递归分屏树，数据模型：

LeafPane = { kind: 'leaf', tabs: TabEntry[], activeTabId }
SplitPane = { kind: 'split', dir: 'h' | 'v', ratio: 0-1, a: PaneNode, b: PaneNode }
PaneNode = LeafPane | SplitPane

拖动手柄：透明间隙 var(--ide-frame-pane-inset-h) + 居中 4×44px 胶囊，hover 时 45% 白 + 56px 高。::before 扩展抓取区 ±5px。ratio 限制 [0.1, 0.9]。

Tab 拖拽分屏：拖动 tab 到另一个 pane 时显示 5 个 DropZone（中/左/右/上/下），放入中间合并标签，放入四边创建新 SplitPane（50/50）。

叶子 Pane：实底 var(--background) + 圆角 var(--radius-md) + 边框 + 阴影。iframe 加载页面内容，不继承宿主 CSS。

交互模式：哪些奏效，哪些被推翻

三次架构重构的代价换来的判断。

Worked
  • 泳道 + 浮层卡分层：泳道铺全景、点击弹聚焦卡做深编辑
  • hover 才显的操作：删除叉、虚线关联默认隐藏
  • SVG 连线四态：默认灰→active→dim→dashed hover
  • 配置引导链路：步号变橙 + 顶部横幅 chip 跳转
  • 表头筛选替代左侧列表：100+ 条数据时更高效
  • 整机总览并入导航树：父子数据放同一棵树
Failed
  • 纯节点图：传感器增多后连线交叉、布局跳动
  • 聚焦发光框：暗色主题下 glow 刺眼且混淆选中态
  • 每步彩色状态标签：页面被色块填满，分散注意力
  • 独立浮层做概览：增加跳转成本，与导航树分裂
  • 左侧列表做多维筛选：数据量大时效率低
  • 常驻显示所有操作按钮：视觉噪声高

信息密度控制

7 次 declutter 提交总结出的决策框架。

Q1

这条信息在 80% 的操作路径中必须吗？

不必须→收进 hover tooltip 或展开面板。

Q2

这个操作按钮在浏览态需要吗？

不需要→默认隐藏，hover 时显示。

Q3

这个功能入口在别处已经有了吗？

有→删掉重复的。

Q4

这一级标题和上一级有区分度吗？

没有→合并层级。

iframe / 独立页面踩坑记录

IDE demo 的页面运行在 iframe 中，这带来了一组独特的约束。

!

iframe 不继承宿主 CSS

每个 public/ 页面必须自带完整 :root token 和滚动条规则。

!

嵌入面板的 z-index 和 safe-distance

position: absolute/fixed 元素会被 topbar（48px）遮挡。

!

postMessage 联动格式固定

{ type:'ai-run-agent', cmd:'agent <关键词>' }，关键词须命中 AgentTerminal 词表。

!

全屏页 vs 嵌入页背景不同

全屏用蓝紫渐变 + #181B20；嵌入 IDE pane 用实底 #101010。

给下一次的流程建议

如果重来一次，这些流程能减少至少一半的 polish 提交。

1

先 mock 再实现

配置型 UI 先用低保真原型确认方向。报警配置 4 次重构是最大返工源。

2

新组件过信息密度清单

上线前用 Q1-Q4 四个问题过滤一遍。从「最小信息量」开始。

3

Token 优先于数值

硬编码数值都会被后续改掉。改用 CSS 变量引用 design token。

4

用脚手架 skill 起步

新建页面时用 public-page-scaffold skill（A-G 七种模板），从源头消除 R1/R2 违规。

5

自动检查跟着约束走

每条新增视觉约束，能用正则检查就立即加进 check-ui-style.mjs。

自动检查规则速查（R1-R8）

scripts/check-ui-style.mjs，PostToolUse hook 每次 Write/Edit 后自动运行。

R1

全局深色滚动条

必须包含 ::-webkit-scrollbar + scrollbar-width: thin。

R2

禁用蓝紫配色

AI/agent 强调色只允许 #a78bfa（紫）/ #0077FF（蓝），禁止 #4F46E5 #5b8af5 #6159ef 等私造 indigo/violet。

R3

面型图标

AI/agent 入口必须是 fill 型 ✦ 四角星，禁止描边星形 stroke="currentColor"。

R4

白描边上限

border: 1px solid rgba(255,255,255 每页最多 2 处，超出请用填充色分层。

R5

嵌入页禁渐变

嵌入 IDE pane 的页面禁止蓝紫渐变背景，必须实底 #101010。渐变仅限 welcome 系全屏页面。

R6

:root token 完整声明

每个独立 HTML 页面必须声明 --background、--surface-1、--primary 三个 token。

R7

胶囊造型强制

按钮/chip/输入框 border-radius 只允许 100px 或 999px，禁止 8px/12px。卡片 16px 不受约束。

R8

禁用私造绿色

成功色只允许 #04d793，禁止 #3dd68c #10b981 #34d399 等。
