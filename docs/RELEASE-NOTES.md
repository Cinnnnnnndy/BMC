# openUBMC Studio 更新日志与交互说明

> 2026-08-03 · 设计原型（Web Demo）· 在线版：Pages 站点 `release-notes.html`（欢迎页 →「新功能介绍」）

## 更新日志（2026-08-03）

### MCP 功能扩展 — 红色状态即入口（NEW）
- **全局惯例**：任何红色/警告状态旁均新增 agent 派发入口，用户看到问题即刻可让 agent 介入。
- 状态栏问题计数（⚠）点击直接触发 `agent 校验修复当前 CSR`，不再只是打开终端。
- BMC 环境管理：不可达节点（BMC-A03）的树行、详情面板、通知 toast 均新增 `✦ 诊断` 按钮，一键派发 `agent 节点诊断`。
- 失败执行记录行新增 `✦ 诊断` 入口；不可达统计卡片可点击触发诊断。

### CSR 校验 + 自动修复闭环（NEW）
- 新增 agent 任务 `校验修复`：首轮 `csr_validate` → 识别未引用对象 → `csr_resolve_unused_objects` 自动清理 → 复验确认。
- 拓扑/CSR 视图 tab 行动作从单一「校验」升级为「校验修复 | 出包检查」双按钮。

### 事件仿真演练 — 端到端验证（NEW）
- 新增 agent 任务 `演练`：校验事件配置 → 仿真注入故障 → 验证事件触发 → 报告链路完整性。
- 事件配置、传感器配置、仿真调试视图 tab 行均新增「演练」快捷按钮。
- AI 助手新增「事件仿真演练」示例场景。

### 器件挂载 + 配置骨架生成（NEW）
- 新增 agent 任务 `挂载芯片`/`添加器件`：根据器件型号自动生成 Chip + Scanner + ThresholdSensor + Event 完整骨架。
- AI 助手新增「器件挂载 + 配置骨架生成」示例场景。

### 出包前置检查（NEW）
- 新增 agent 任务 `出包检查`：CSR 校验 + 签名配置 + 管道表达式求值 + 版本一致性，四项联合检查。

### Docker 容器诊断恢复（NEW）
- 新增 agent 任务 `容器诊断`：检查异常容器状态、自动恢复 Exited 容器。

### MCP 工具扩展
- MCP 工具总数从 26 增至 30：新增 `csr_resolve_unused_objects`、`csr_generate_skeleton`、`sim_verify_event_chain`。
- agent help 示例更新，覆盖全部新增任务场景。

## 更新日志（2026-07-16）

### 底栏 agent 终端（NEW）
- 工作区底部新增 openUBMC agent CLI 终端 dock：`agent <任务>` 一句话派发任务，自动回放 MCP 工具调用轨迹，完成后分屏打开关联功能视图。

## 交互说明

### 布局总览
活动栏（功能入口 + 「···」收纳）｜顶栏（品牌 / 当前工程 / 全局动作：终端 · 全屏 · 深浅色 · AI）｜工作区（多 tab 多 pane，拖拽分屏，tab 行右侧为上下文动作）｜底栏终端（执行流）+ 右侧 AI 面板（对话流）｜状态栏（连接与问题，条目可点击直达）。

### 上下文动作（tab 行右侧）
| 激活的功能页 | 动作 | 行为 |
|---|---|---|
| BMC 环境管理 | 巡检 | `agent 巡检在线 BMC` |
| 拓扑 / CSR 拓扑 / 事件 / 传感器 | 校验 | `agent 校验当前 CSR` |
| CSR 编辑类视图（已加载工程） | 出包 | 下载/保存 CSR，无修改置灰 |

### agent 终端命令
| 命令 | 说明 |
|---|---|
| `agent <任务描述>` | 匹配任务场景，回放 MCP 工具轨迹，完成后分屏打开关联视图 |
| `mcp` | 列出 7 个 MCP Server / 26 个工具 |
| `open <视图>` | env / topo / event / sensor / smc / expr / explorer / setup / sim / 3d / cooling / welcome / ai |
| `views` | 列出视图别名 |
| `clear` / `exit` | 清屏 / 关闭终端 |

### AI 辅助安装引导路径
安装引导 → 登录 → 下一步 → 配置检测（失败）→ 让 agent 诊断修复 → 终端诊断 6 项、修复 2 项 → Step 2.2 翻绿、下一步解锁。
账号授权类操作（登录官网、GitCode 公钥上传）仍需本人完成；写操作在 AI 面板对话版中有审批门。

### 硬件管理器（CSR 拓扑左栏）
类别 → 板卡组（状态色点：绿已解析/橙多匹配/黄待选/红缺失/灰未分类，点击联动画布）→ 文件行（`PartNumber_…SN尾号.sr`，悬停看全名，点击切换画布实例）；未分类可「指派」到空槽位。

BMC 3/5 可达（→环境管理）｜SSH 1（→环境管理）｜Docker 2/3（→巡检任务）｜⊗0 ⚠2（→输出面板）｜MCP 7（→终端工具清单）｜终端（开关）。
